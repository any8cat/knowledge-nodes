# 知识节点

一个只在本地使用的复习小工具：把要背的知识点建成「节点」，给节点配笔记图片，
忘了就点一下「忘记了」，临考前按「忘过次数」排序，一眼看出哪个知识点最容易被忘掉。

- 单机、离线，不需要注册和联网；
- 数据只存在本机的 `data` 文件夹里，不会上传到任何地方；
- 界面和提示都是中文。

> 这个仓库**不包含任何个人数据**：`data` 文件夹（数据库和笔记图片）已被
> `.gitignore` 排除，第一次运行程序时会自动创建。

## 怎么启动

### 方式一：直接运行 exe（不用装 Python）

1. 下载本仓库（点页面右上角的 `Code` → `Download ZIP`，或克隆仓库）；
2. 解压后进入 `dist\知识节点\`；
3. 双击 `知识节点.exe`。

`知识节点.exe` 和旁边的 `_internal` 文件夹必须放在一起，不能只把 exe 单独拷走。
第一次运行会在 exe 旁边自动创建 `data` 文件夹。

> 如果 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。
> 这是没有购买代码签名证书时 Windows 的常规提示。

### 方式二：从源码运行

需要 Python 3.12（安装时勾选「Add python.exe to PATH」），并安装拖放图片用的
`tkinterdnd2`：

```bat
py -m pip install tkinterdnd2
```

然后在项目根目录双击 `Start-知识节点.bat`。

源码方式的 `data` 文件夹在项目根目录；exe 方式的 `data` 文件夹在 exe 旁边。
两种方式各自使用自己的 `data`，请不要同时用两种方式打开同一份数据。

## data 目录在哪里

- **exe 方式**：`知识节点.exe` 旁边的 `data` 文件夹；
- **源码方式**：项目根目录的 `data` 文件夹。

`data` 文件夹里有两样东西：

- `knowledge.db`：数据库，科目、节点、文字描述、标记记录都在里面；
- `attachments`：笔记图片的副本，按节点分子文件夹存放。

**整个 `data` 文件夹就是全部家当。** 本软件不做自动备份，也没有备份按钮，
请偶尔手动复制一份 `data` 文件夹到 U 盘、移动硬盘或网盘。

> 如果你把 exe 放在 `C:\Program Files` 这类需要管理员权限的目录，程序可能无法在
> 旁边创建 `data`。建议把整个 `dist\知识节点` 文件夹放到 D 盘或桌面上再运行。

## 功能一览

- **科目**：左侧列表，空白处右键「新建科目」，科目上右键可重命名、删除。
- **知识节点**：右侧列表，空白处右键「新建节点」，节点上右键可打开、重命名、删除。
- **搜索**：节点区上方的搜索框，按标题或文字描述筛选当前科目的节点。
- **笔记图片**：节点详情窗里可以拖放图片、Ctrl+V 粘贴图片文件、点「添加图片」按钮选文件；
  支持 png、jpg、jpeg、bmp、gif、webp。双击图片用 Windows 照片打开。
- **标记「忘记了」**：节点右键「忘记了」，当天该行变红并置顶；右键「没忘记」撤销当天的标记。
- **日历**：按科目看整月，红色越深表示那天忘得越多；点日期看当天标记，右键可撤销。
- **统计与排序**：列表显示每个节点「忘过几次」和「最近标记」日期；
  勾选「按忘过次数排序」后按次数从多到少排，当天标记的节点仍然红色，但不再置顶。
- **帮助**：点右上角的「?」按钮，随时打开这份说明的窗口版。

## 常见问题

### 1. 双击 `Start-知识节点.bat` 报错或窗口一闪而过怎么办？

bat 里已经做了处理：程序异常退出时窗口会停住，并显示「程序异常退出」。
请把窗口里的**报错原文**完整复制或截图，不要只描述「打不开」。

常见报错：

- `'py' 不是内部或外部命令`：这台电脑没装 Python，或安装时没勾选
  「Add python.exe to PATH」。重装 Python 3.12 并勾选该选项。
- `No module named tkinterdnd2`：在项目根目录打开命令行，执行
  `py -m pip install tkinterdnd2`。
- `No module named db`：不要直接双击 `app\main.py`，要双击项目根目录的 bat。

### 2. 360 提示病毒或把 exe 删了怎么办？

这是 PyInstaller 打包的程序常见的**误报**，不是真的病毒。处理办法：

1. 不要关闭 360；
2. 打开 360 的「信任区 / 白名单」，把整个 `dist\知识节点` 文件夹加进去；
3. 如果文件已经被隔离，先从隔离区恢复，再加信任；
4. 以后重新打包，先把新的 `dist\知识节点` 文件夹加进信任区再运行。

如果 360 弹出具体拦截提示，请把提示原文截图保存，不要自己改打包方案。

### 3. 数据在哪里？怎么备份？

全部数据都在 `data` 文件夹（见上面「data 目录在哪里」）。
备份方法：关闭软件后，把整个 `data` 文件夹复制到 U 盘、移动硬盘或网盘。
恢复方法：把备份的 `data` 文件夹放回原来的位置，覆盖同名文件夹即可。

本软件**不做自动备份**，也没有备份按钮，请偶尔手动复制一次。

### 4. 截图后按 Ctrl+V 没反应？

本软件只能粘贴「图片文件」，不能直接粘贴截屏得到的位图（因为没有装图片处理库）。
请先在画图等软件里把截图另存为 png 或 jpg 文件，再拖进详情窗或复制该文件后按 Ctrl+V。

### 5. 双击 exe 没反应或打开很慢？

- 文件夹形态的 exe 第一次启动会慢几秒，属正常；
- 确认 `知识节点.exe` 和 `_internal` 文件夹在同一个目录里；
- 如果被杀软拦住，按第 2 条把整个文件夹加入信任区；
- 还不行就双击 bat 用源码方式启动，看具体报错。

### 6. 为什么「忘过次数」一直是 0？

只有右键选过「忘记了」才会计数；仅仅打开节点、看图片都不算。
同一天重复标记只算一次，所以次数等于「有多少天忘了它」。

## 从源码重新打包

只有修改源码后才需要重新打包。安装 PyInstaller 后，在项目根目录执行：

```bat
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --onedir --windowed --name 知识节点 --distpath dist --workpath build --specpath build app\main.py
```

- 打包工具：PyInstaller 6.22.3（仅用于打包，程序运行不需要它）；
- 采用文件夹形态（`--onedir`），不是单文件；
- 输出位置：`dist\知识节点\知识节点.exe`；
- 打包参数不会修改数据目录；exe 始终读取自己旁边的 `data` 文件夹。

## 目录结构

```
知识节点\
├─ Start-知识节点.bat      源码方式启动
├─ README.md               本说明
├─ .gitignore              不上传 data、build 等
├─ app\                    程序源码
│  ├─ main.py              入口
│  ├─ db.py                数据库与统计查询
│  ├─ ui_main.py           主窗口
│  ├─ ui_dialogs.py        节点、日历、帮助等窗口
│  └─ dates.py             「今天」的统一算法
├─ data\                   运行后自动生成，里面是个人数据（不提交）
│  ├─ knowledge.db
│  └─ attachments\
└─ dist\知识节点\          打包后的程序
   ├─ 知识节点.exe
   ├─ _internal\
   └─ data\                exe 第一次运行时自动生成
```
